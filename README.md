## What is ZA Mega Shards?
ZA Mega Shards is a side mod made for Mega Showdown that adds Mega Shards - a renewable resource to tackle one of Mega Showdowns major issues for servers or worlds with limited sizes - The obtainment of Mega Stones. These Shards are **not** gonna be another resource to craft Mega Stones themselves but rather a **Villager trade item** to buy them.

There are two main methods of obtaining Mega Shards and the first one is by finding them underground! In newly generated chunks so called **Mega Energy Clusters** will generate, which behave very similar to Amethysts.


<img src="https://cdn.modrinth.com/data/cached_images/aa5ba866a0070943e4b28f6e93aec78bc71e3040.gif" alt="Cluster growing gif" width="75%">    

These usually constist of 1-3 `Mega Energy Cores` which slowly grow `Mega Energy Buds`,      
eventually turning into `Mega Energy Clusters` that you can break to obtain `Mega Shards`.

Don't like that? - You can disable their generation! _(check the `Config & Datapacks` section)_

### What are my Stones worth?:
**Tier 1**: 32x Mega Shards    
**Tier 2**: 40x Mega Shards    
**Tier 3**: 48x Mega Shards    
**Tier 4**: 56x Mega Shards    
**Tier 5**: 64x Mega Shards

Don't like that? - You can configure/disable it! _(check the `Config & Datapacks` section)_









![MEGA RESEARCHER divider](https://cdn.modrinth.com/data/cached_images/05927cfac4aa37eb76bb81a276bb623835cdf0f0.png)

The ZA Mega Shards Villager - The _"Mega Researcher"_ - sells you lots of Mega Stones. Its shop gets 2-3 new ones per rank & at Master Rank it can either give you access to a Legendary Mega Stone or a Blank one, making people able to farm for infinite stones _even with limited worlds_.

<img src="https://cdn.modrinth.com/data/cached_images/b5a2f2020a3c06c0b4775b5b87748289df4b4d01.png" alt="Mega Researcher" width="51%"> <img src="https://cdn.modrinth.com/data/cached_images/9aa66019972c37b6b0fbd0c457e1d22e1203cffa.gif" alt="Mega Researcher Trades" width="48%">      
Prices too high/low? - These are configurable! _(check the `Config & Datapacks` section)_

### Each Villager Tier adds more Stones the Villager offers:

**Novice**: 1-3 Tier 1 Mega Stones    
**Apprentice**: 1-3 Tier 2 Mega Stones    
**Journeyman**: 1-3 Tier 3 Mega Stones    
**Expert**: 1-3 Tier 4 Mega Stones    
**Master**: one Tier 5 Mega Stone or a Blank Mega Stone











![MEGA STONE TIERS divider](https://cdn.modrinth.com/data/cached_images/e58c877c9909a0e03134b6a9887c418e2f04e288.png)

By default all Mega Stone are separated into five tiers. they follow these "rules":    
**Tier 1-4**: feature Mega Stones in increasing viability for competitive play    
**Tier 4**: specifically also has all three Z Mega Stones    
**Tier 5**: is reserved for Legendary/Mythical Mega Stones as well as the Blank Mega Stone

## Datapackable features:

<details>
<summary>Click for more detail!</summary>

What if you don't like the default Tiers or want to expand on it? Well - change the tag! by including it in your addon/mod under `/data/za_mega_shards/tags/item/mega_stone_tier_X.json` - where X will be the tier you want to replace/add to.

### Replace the mods default tiers:

<details>
<summary>Click for more detail!</summary>

```json
{
  "replace": true,                     //false=add to the mods' tag, true=replace the mods' tag default
  "values": [
    "mega_showdown:mewtwonite_x",      // add any item you want
    "mega_showdown:mewtwonite_y"       // add any amount of items you want
  ]
}
```
The example above would **replace** the base mods tier you edited.     
**NOTE**: Do not add these comments (//) inside your files!
</details>

### Add your own Mega Stones/items:

<details>
<summary>Click for more detail!</summary>

Say you want to add your own mods' Mega Stones to this mods' Villager & Workstation?

```json
{
  "replace": false,                   //false=add to the mods' tag, true=replace the mods' tag
  "values": [
    "lost_lore:shadow_mewtwonite_x",  // add any item you want!
    "lost_lore:shadow_mewtwonite_y"   // add any amount of items you want
  ]
}
```
The example above would **add to** the base mods tier you edited.     
**NOTE**: Do not add these comments (//) inside your files!
</details>

</details>

## Config Features:

<details>
<summary>Click for more detail!</summary>

Everything in here should be pretty self explanatory but I added comments to the config itself so you can always look it up as well!

```toml
# Prices when trading with the Mega Researcher Villager
# DEFAULT: 64, 80, 96, 112, 128
# RANGE: 1 - 128 anything outside will result in the DEFAULT being used

[mega_stone_buy_prices]
tier_1 = 64
tier_2 = 80
tier_3 = 96
tier_4 = 112
tier_5 = 128


# Worth of Stones when using the Mega Research Station
# DEFAULT: 32, 40, 48, 56, 64
# RANGE: 1 - 64 anything outside will result in the DEFAULT being used

[mega_stone_shard_returns]
tier_1 = 32
tier_2 = 40
tier_3 = 48
tier_4 = 56
tier_5 = 64


# Whether Mega Stones can be disassembled into Mega Shards
# The Research Station can still be used as a villager workstation when disabled
# DEFAULT: true

[research_station]
enable_disassembly = true


# Whether Mega Energy Deposits generate naturally
# Existing deposits are not removed when disabled
# Requires a game/server restart to take effect
# DEFAULT: true

[world_generation]
enable_mega_energy_deposits = true


# Maximum number of uses per Mega Researcher trade before restocking
# Existing villager offers retain their previously generated limits
# DEFAULT: 4
# RANGE: 1 - 64 anything outside will result in the DEFAULT being used

[mega_researcher]
max_trades_per_offer = 4
```

</details>

### /za_mega_shards info
Requires operator permission level 2 & prints out a fair bit of relevant information like:
- Installed ZA Mega Shards version
- Total amount of registered Mega Stones _(including addons)_ in total & per tier
- Show purchase prices currently set in the config
- Show disassembly worth currently set in the config
- Show whether disassembly & natural deposit generation are enabled/disabled
- Display the configured maximum uses per villager trade
